# Saved motions

Recordings made in the dashboard's **Record** tab are saved here as JSON (one file per motion)
and appear under **Your recordings** in the **Motions** tab. Commit the ones you want to keep:
they replay on any PC with the same robot profile.

Built-in motions (hello, scare, dance) live in code: `so101_dashboard/motions.py`.
Set `SO101_MOTIONS_DIR` to keep recordings somewhere else.
